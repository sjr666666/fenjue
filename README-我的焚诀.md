## 4. 我的红线（每场面试前默念）

1. **永不编**：指标、规模、交付状态没核实过的，一律"这块我手头没有第一手数据" + 给出核实路径；量化只在有口径时说。
2. **简历口径不升格**：我的真实口径是"导师带队企业项目中的核心开发成员，独立负责两个 Agent 应用端"——Runtime 底座是团队/开源底座，我做的是应用端工程化，被剥离集体功劳时守住这条线。
3. **技术挂业务**：每个技术点先讲它解决哪个业务问题（获客流失 / 换模型成本 / 渠道 SDK 绑死 / 多人并行污染）。
4. **主动讲边界优于被问出来**：profile 并发写冲突、WhatsApp 逆向协议风险、sending 后模糊超时不可重试——这些已知边界我先说。
